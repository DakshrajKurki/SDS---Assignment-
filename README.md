# 🎮 Video Game Sales Analysis (1980–2020)

An exploratory and statistical analysis of four decades of **global video game sales** — which genres, platforms and publishers dominate, how the market changed over time, and how regional sales relate to each other.

## Dataset

Each record is a game with its title, platform, release year, genre and publisher, plus sales in **North America, Europe, Japan, Other regions** and **Global** totals.

## Analysis

| Area | Question answered |
|---|---|
| Data cleaning | Handle missing years/publishers, fix types |
| Descriptive statistics | Typical and extreme sales figures by region |
| Genre analysis | Which genres are released most, and which sell the most |
| Platform analysis | Which platforms generated the highest sales |
| Publisher performance | Top publishers by total global sales |
| Time series | Number of releases and total sales per year |
| Correlation | How NA, EU, JP and Other sales move together |
| Top sellers | The 10 best-selling games worldwide |
